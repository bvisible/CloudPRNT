# Security

Please report a security issue privately, by e-mail to **hello@neoservice.ai**, and not in a public issue
or pull request. Describe the affected file and commit, how to reproduce it, and what it lets an attacker do.

We confirm receipt, fix the issue on the `version-15` branch, roll the fix out to the instances we host, and
then publish an advisory on this repository, crediting the reporter if they wish.
